# Sistema de Clínica

## Status do Projeto

Em desenvolvimento.

## Tecnologias Utilizadas

* Java
* Java Swing
* JDBC
* MySQL
* Git
* GitHub
* Apache Maven

## Desenvolvedor

* Kayky Mendes

## Objetivo do Software

Desenvolver um sistema desktop para gerenciamento de uma clínica médica, permitindo o cadastro de pacientes, médicos e consultas, utilizando banco de dados MySQL para armazenamento das informações.

## Funcionalidades

* Login no sistema
* Cadastro de pacientes
* Cadastro de médicos
* Agendamento de consultas
* Listagem de pacientes
* Listagem de médicos
* Listagem de consultas
* Integração com banco de dados MySQL
* Persistência de dados

## Banco de Dados

O sistema utiliza o banco de dados MySQL denominado:

clinica_pi
